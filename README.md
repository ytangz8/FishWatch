# FishWatch

在 Windows 上监控屏幕指定区域，出现上鱼图标就自动双击。自带 Web 控制台，Mac 或手机用浏览器即可查看状态和日志。

## 运行（Windows）

1. 安装 Python 3.10+（安装时勾选 "Add python.exe to PATH"）。
2. 双击 `start.bat`。首次运行会自动创建 `.venv` 并安装依赖。
3. 控制台窗口会打印访问地址，例如 `http://192.168.1.23:8765/`。

**如果游戏以管理员身份运行，start.bat 也要右键以管理员身份运行**，否则 Windows 会静默拦截模拟点击（UIPI）。

## Mac 访问

浏览器打开控制台打印出的地址。如果打不开，在 Windows 上以管理员身份执行下面的命令放行端口：

```bat
netsh advfirewall firewall add rule name="FishWatch" dir=in action=allow protocol=TCP localport=8765 profile=private
```

同时确认 Windows 的网络类型是「专用网络」。如需访问口令，在 `config.json` 中设置 `"token": "xxx"` 后重启，访问时使用 `http://ip:8765/?token=xxx`。

## 首次配置

1. 在游戏里等上鱼图标出现，然后在网页上点「刷新截图」。截图会缓存，图标消失也没关系。
2. 在截图上**紧贴图标**框选，可在右侧放大图和坐标框里微调，然后点「保存为模板」。如果还没有设置检测区域，会自动以图标为中心向外扩 60px 作为检测区域。
3. 如果图标出现的位置会漂移，框一个更大的范围，点「设为检测区域」。
4. 观察「匹配分数」：图标出现时分数应接近 1，没有图标时应明显偏低（通常 < 0.5）。把阈值设在两者之间。
5. 点「测试双击」，3 秒内切回游戏，确认游戏能响应模拟点击。
6. 点「开始」。在 Windows 本机按 **F8** 可随时暂停或恢复。

如果需要双击的位置不是图标本身（比如要点收杆按钮），框选该按钮后点「选区中心设为固定点击点」。

## 入护判定（可选）

每次双击上鱼之后，程序会接着判断另一个区域里有没有「入护图标」：

```
双击上鱼 → 等待「等待时间」→ 在「判定窗口」内反复检测入护区域
            ├─ 任一帧分数 ≥ 入护阈值 → 立即按「有图标时按」的键（默认空格，入护）
            └─ 整个窗口都没命中      → 按「无图标时按」的键（默认 Backspace，释放）
→ 开始计算冷却时间
```

配置步骤：

1. 等结算界面出现，并且界面上有入护图标时，在「框选区域 / 模板」里选择「入护图标」，点「刷新截图」，框选图标后点「保存为模板」。系统会自动生成入护检测区域；如果需要调整，框选范围后点「设为检测区域」。
2. 在「运行状态」里观察「入护分数」：有图标时应接近 1，没有图标时应明显偏低。据此设置入护阈值。「测试判定」按钮会立即判定一次并显示结果，不会真的按键。
3. 「等待时间」设为「双击后到结算界面完全出现」所需的时间，宁长勿短。如果判定得太早，界面还没出来，就会被误判为「释放」。
4. 在参数里把「启用入护判定」设为「是」。

注意：「无图标就释放」意味着，只要结算界面出现得比预期晚，就会误按 Backspace。如果拿不准时间，就把「判定窗口」设得宽一些（比如 2000ms）。有图标时一命中就会立即按键，不必等窗口结束，所以窗口设宽不会拖慢入护。

## 参数要点

| 参数 | 说明 |
|---|---|
| 匹配阈值 | 误触发就调高，漏触发就调低 |
| 连续命中帧数 | 默认 2 帧，检测间隔 50ms 时约 100ms 确认 |
| 冷却 | 双击后这段时间内不再触发 |
| 图标消失多久才重新触发 | 双击后会上锁，直到图标连续消失这么久才允许下一次触发，防止拉鱼过程中图标还在而被重复双击。默认 500ms，0 = 关闭 |
| 点击延迟 | 部分游戏需要等动画结束才响应 |
| 灰度匹配 | 如果有形状相同、颜色不同的图标需要区分，关闭此项 |
| 冷却 | 从整轮操作（双击 + 入护判定 + 按键）结束后开始计时 |
| 按键按住 | 按键按下到松开的时长。游戏没反应时可以调到 80–100ms |

## 文件

- `config.json`：所有配置，网页上修改后自动保存
- `template.png`：模板图
- `events.jsonl`：事件日志
- `snapshots/`：每次触发时检测区域的截图（保留最近 100 张），用于排查误触发
- `fishwatch.log`：运行日志

## 已知限制

- 截图使用 GDI（mss）。全屏独占模式的游戏可能截到黑屏，请改为窗口化或无边框窗口。
- 游戏窗口必须可见。被其他窗口遮挡或最小化时检测不到图标，点击也会落到错误的窗口上。
- 坐标是屏幕绝对像素。游戏窗口移动、分辨率或缩放比例改变后，需要重新框选。
- 模拟点击在部分网游中可能违反用户协议，有封号风险，请自行评估。

## 在其他系统调试

```bash
FISHWATCH_FAKE_SCREEN=screen.png python app.py   # 用一张图片当作屏幕，点击为 dry-run
```

## 更新代码

首次在 Windows 上部署：

```bat
git clone <仓库地址> fishwatch
cd fishwatch
start.bat
```

之后每次仓库有更新，双击 `update.bat`。它会依次停掉正在运行的实例、执行 `git pull`、安装新增的依赖，然后重新启动。

`config.json`、`template.png`、`keep_template.png`、`events.jsonl`、`snapshots/` 都在 `.gitignore` 里，更新不会覆盖本机已经调好的模板和参数。
